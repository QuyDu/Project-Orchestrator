## Purpose

Explain how Project Orchestrator turns a repository into a governed GitHub Copilot workspace without presenting planned work or release readiness as delivered capability.

- Audience: Technical practitioners.
- State: Current verified repository evidence.
- Treatment: Architectural miniature exhibit.

## Layout And Materials

- Foreground: a wooden label rail reading `Current repository -> governed workspace`, with paper approval tokens and a small validation checklist.
- Middle ground: the central desk and the four connected work areas. Use cardstock, wood, translucent acetate, tiny file folders, and restrained colored pins.
- Background: a shallow workshop wall with a single framed workflow sketch. Keep the surface plain enough for labels to remain readable.
- Lighting: warm directional studio key light, soft fill light, visible cast and contact shadows, and a perspective camera at tabletop height.
- Palette: focus purple for the orchestration desk, dark green for validated routes, red only for blocked or approval-gated paths, and black or neutral paper for supporting labels.
