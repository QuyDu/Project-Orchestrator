Step 1 · Trust, then use

Verify the checkout before provisioning.

Skills Orchestrator uses Node.js built-ins and no runtime packages. Verification checks its complete distribution.

PowerShell
PS> git clone https://github.com/QuyDu/Project-Orchestrator.git
PS> cd Project-Orchestrator
PS> node .\pso.mjs verify
✓ Verified registry-free distribution

Step 2 · New repository

Create a governed project in one command.

Choose a profile and technology stack. The generated workspace includes empty source boundaries, CI wiring, and the complete skill system.

PowerShell
PS> node .\pso.mjs create-project `
  --name "My Project" `
  --destination "C:\Projects" `
  --profile durable `
  --stack typescript `
  --open `
  --accept-risk

✓ Project foundation verified
✓ Workspace ready to open

Or · Existing repository

Preview adoption. Apply only what is missing.

Detection finds the stack, preserves project-owned instructions, avoids duplicate standards, and journals every mutation.

PowerShell
PS> node .\pso.mjs adopt `
  --project "C:\repos\ExistingProject" `
  --profile core --dry-run

Detected stack: python, tests
Files to create: 24
Blocking conflicts: 0

PS> node .\pso.mjs adopt `
  --project "C:\repos\ExistingProject" `
  --profile core --apply --accept-risk
